# Practical 1: MetaMask installation and Ether transaction fee study

This is a wallet/network exercise, not a Solidity coding practical.

1. Install MetaMask only from its official website or browser/mobile app store.
2. Create a wallet and securely back up the Secret Recovery Phrase offline. Never share it.
3. Switch to a test network (for example, Sepolia) and obtain test ETH from a reputable faucet.
4. Send a small test transaction to another test wallet.
5. Open the transaction in the network explorer and record: transaction hash, gas used, gas price, and transaction fee.
6. Fee in ETH = gas used × effective gas price (in ETH per gas unit).
7. Do not use real funds for classroom experiments. Never enter a recovery phrase into a website or share it with anyone.


# Practical 2: Create a wallet using MetaMask

1. Install MetaMask from the official source.
2. Select Create a new wallet and set a strong local password.
3. Write the Secret Recovery Phrase on paper and store it securely offline.
4. Confirm the phrase in MetaMask. Do not take screenshots or share it.
5. Copy the public wallet address for receiving test tokens.
6. Switch to a test network and receive test ETH from a faucet.
7. Verify the received transaction using the block explorer.

Security: anyone with the Secret Recovery Phrase can control the wallet. Never share it.



# Practical 5: Survey report on types of blockchains and real-time use cases

Use this outline for the written survey report (no program is required by the index).

1. Introduction to blockchain
2. Public blockchain: open participation; examples include Bitcoin and Ethereum
3. Private blockchain: access controlled by one organization
4. Consortium/Federated blockchain: operated by a group of organizations
5. Hybrid blockchain: combines permissioned and public elements
6. Compare decentralization, privacy, scalability, governance, and cost
7. Use cases: payments, supply chain tracking, digital identity, healthcare audit trails, and e-voting prototypes
8. Discuss limitations: throughput, energy use (depending on consensus), privacy, regulation, and key management
9. Conclusion and references

Clearly distinguish deployed production use cases from pilots or proposals.
